ΟΡΟΛΟΓΙΚΟΣ ΔΙΑΧΩΡΙΣΜΟΣ ΤΩΝ ΤΥΠΩΝ ΤΗΣ ΤΕΣΝ

1. ANTI-GBM ΑΝΤΙΣΩΜΑΤΑ (+):

• Διαγιγνώσκουν ΤΕΣΝ Τύπου Ι (Anti-GBM Νεφρίτιδα / Goodpasture)

• Επίπεδα Συμπληρώματος C3 / C4: ΦΥΣΙΟΛΟΓΙΚΑ

2. ANCA ΑΝΤΙΣΩΜΑΤΑ (+) (c-ANCA / PR3-ANCA ή p-ANCA / MPO-ANCA):

• Διαγιγνώσκουν ΤΕΣΝ Τύπου ΙΙΙ (Pauci-Immune ANCA Αγγειίτιδες)

• Επίπεδα Συμπληρώματος C3 / C4: ΦΥΣΙΟΛΟΓΙΚΑ

3. ΕΛΑΤΤΩΜΕΝΑ ΕΠΙΠΕΔΑ ΣΥΜΠΛΗΡΩΜΑΤΟΣ (C3, C4 < Φ.Τ.):

• Διαγιγνώσκουν ΤΕΣΝ Τύπου ΙΙ (Ανοσοσυμπλεγματική)

• Αίτια: Νεφρίτιδα Λύκου (ΑΝΑ/dsDNA+), Μεταστρεπτοκοκκική ΣΝ (ASTO+),

MPGN, Κρυοσφαιριναιμία (HCV+).
