ΔΙΑΦΟΡΙIΗ ΔΙΑΓΝΩΣΗ ΟΞΕΙΑΣ ΠΥΕΛΟΝΕΦΡΙΤΙΔΑΣ

1. Οξέα Ενδοκοιλιακά Νοσήματα:

• Οξεία Σκωληκοειδίτιδα (ιδίως οπισθοτυφλική).

• Οξεία Χολοκυστίτιδα / Χολαγγειίτιδα.

• Εκκολπωματίτιδα Αριστερού / Δεξιού Κόλου.

• Οξεία Παγκρεατίτιδα.

2. Γυναικολογικές Παθήσεις:

• Οξεία Σαλπιγγίτιδα / Φλεγμονώδης Νόσος της Πυέλου (PID).

• Ρήξη / Στροφή Κύστης Ωοθήκης.

• Έκτοπος Iύηση.

3. Λοιπές Νεφρικές / Ουρολογικές Παθήσεις:

• Νεφρικό / Περινεφρικό Απόστημα (Renal / Perinephric Abscess).

• Οξεία Νεφρική Iολική (Νεφρολιθίαση).

• Οξεία Βακτηριακή Προστατίτιδα στους άνδρες.

• Έμφρακτο Νεφρού / Θρόμβωση Νεφρικής Φλέβας.
