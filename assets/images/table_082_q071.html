ΑΙΤΙΟΛΟΓΙIΗ ΤΑΞΙΝΟΜΗΣΗ ΝΕΦΡΩΣΙIΟΥ ΣΥΝΔΡΟΜΟΥ

α) ΠΡΩΤΟΠΑΘΗ ΑΙΤΙΑ (ΙΔΙΟΠΑΘΕΙΣ ΠΟΔΟIΥΤΤΑΡΟΠΑΘΕΙΕΣ):

1. Νόσος Ελάχιστων Αλλοιώσεων (Minimal Change Disease - MCD):

• Συχνότερο αίτιο στα Παιδιά (80-90%). Οπτικό μικροσκόπιο φυσιολογικό.

• Ηλεκτρονικό μικροσκόπιο: Εξάλειψη ποδοειδών προσεκβολών.

2. Μεμβρανώδης Νεφροπάθεια (Membranous Nephropathy - MN):

• Συχνότερο αίτιο στους Ενήλικες (>50 ετών).

• Αυτοαντίσωμα έναντι του υποδοχέα PLA2R (80%). Υπεπεθηλιακές αιχμές

(spikes) στη GBM.

3. Εστιακή Τμηματική Σπειραματοσκλήρυνση (FSGS):

• Συχνότερο αίτιο σε αφροαμερικανούς και ασθενείς με HIV/παχυσαρκία.

4. Μεμβρανοϋπερπλαστική Σπειραματονεφρίτιδα (MPGN):

• Διπλό περίγραμμα GBM (tram-track appearance).

β) ΔΕΥΤΕΡΟΠΑΘΗ ΑΙΤΙΑ (ΣΥΣΤΗΜΑΤΙIΑ ΝΟΣΗΜΑΤΑ):

1. Σακχαρώδης Διαβήτης: Διαβητική νεφροπάθεια (Kimmelstiel-Wilson).

2. Συστηματικός Ερυθηματώδης Λύκος (ΣΕΛ): Νεφρίτιδα λύκου Τάξη V.

3. Συστηματική Αμυλοείδωση (AL / AA): Εναπόθεση αμυλοειδούς.

4. Λοιμώξεις: Ιογενής Ηπατίτιδα B & C (MN/MPGN), HIV (HIVAN), Σύφιλη.

5. Νεοπλάσματα: Συμπαγείς όγκοι (MN), Λέμφωμα Hodgkin (MCD).

6. Φάρμακα: ΜΣΑΦ, πενικιλλαμίνη, χρυσός, παμιδρονάτη.
